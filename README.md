# Python-Daily-Task-Manager
A beginner-friendly Python CLI mini project to add, view, and delete daily tasks using lists and functions.
# Daily Task Manager

## About the Project
Daily Task Manager is a simple Python command-line mini project that helps users manage their daily tasks.

## Features
- Add new tasks
- View all tasks
- Delete tasks
- Simple menu-driven interface

## Technologies Used
- Python
- Lists
- Functions
- Loops
- Conditional Statements

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the terminal.
4. Run the following command:

```bash
python todo_list.py
```
